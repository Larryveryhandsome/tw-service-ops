# 金鑰申請與設定（要串接外部服務才需要）

示範版（`python app/demo_server.py`）**不需要任何金鑰**，而且會封鎖所有對外連線。
以下只有在你要把系統改成正式使用、串接自己的帳號時才需要。本 repo 不附任何金鑰。

## 金鑰放哪裡

所有金鑰都先從**環境變數**讀，名稱規則：`OPS_SECRET_` ＋ 金鑰名稱（英文大寫、非英數改底線）。沒設定＝空值＝該功能關閉。

| 用途 | 金鑰名稱 | 環境變數 |
|---|---|---|
| LINE 官方帳號（每個品牌一組，`<品牌>` 例如 `demoshop`） | `line_secret_<品牌>`、`line_token_<品牌>` | `OPS_SECRET_LINE_SECRET_DEMOSHOP`、`OPS_SECRET_LINE_TOKEN_DEMOSHOP` |
| LINE Pay（共用一組；也可每品牌一組加 `_<品牌>`） | `linepay_channel_id`、`linepay_channel_secret` | `OPS_SECRET_LINEPAY_CHANNEL_ID`、`OPS_SECRET_LINEPAY_CHANNEL_SECRET` |
| Google 日曆（OAuth） | `google_client_id`、`google_client_secret`、`google_refresh_token` | `OPS_SECRET_GOOGLE_CLIENT_ID` … |
| Anthropic（AI 記帳收據辨識、對話重點） | `anthropic_api_key` | `OPS_SECRET_ANTHROPIC_API_KEY` |
| 照片網址簽章、日曆訂閱網址（系統自己產生，通常不用設） | `photo_url_key`、`calendar_feed_token` | — |

其他設定：

| 環境變數 | 說明 | 預設 |
|---|---|---|
| `OPS_DATA` | 資料庫與上傳檔案的資料夾 | `<專案>/data` |
| `OPS_PORT` | `server.py` 的埠（示範版用 `DEMO_PORT`） | 4781 |
| `OPS_PUBLIC_HOSTS` | 對外網址（逗號分隔），經 HTTPS 反向代理／Tunnel 進來 | `ops.example.com` |
| `OPS_OWNER_LINE_UID` | 負責人的 LINE userId（系統通知送給他） | 空＝不送 |
| `OPS_NO_PUSH` | 設成 `1` 就不發任何 LINE／推播／金流請求 | 正式版不設；示範版固定 `1` |
| `OPS_LOCAL_LLM_DIR` | 本機模型閘道資料夾（要有 `local_llm.chat(system, user)`），客戶訊息不出本機 | 空＝不用 |

> Windows 也可以在畫面上（「設定」各頁）貼金鑰，系統用 Windows DPAPI 加密存進資料庫；Linux／macOS 一律用環境變數。
> 金鑰**不要**寫進程式碼、`.env` 也不要 commit（`.gitignore` 已排除）。

設定方式範例：

```bash
# macOS／Linux
export OPS_SECRET_LINE_SECRET_DEMOSHOP="你的 Channel secret"
export OPS_SECRET_LINE_TOKEN_DEMOSHOP="你的 Channel access token"
python app/server.py
```

```powershell
# Windows PowerShell
$env:OPS_SECRET_LINE_SECRET_DEMOSHOP = "你的 Channel secret"
$env:OPS_SECRET_LINE_TOKEN_DEMOSHOP = "你的 Channel access token"
python app\server.py
```

## 1. LINE 官方帳號（Messaging API）

1. 到 [LINE Official Account Manager](https://manager.line.biz/) 建立官方帳號（免費方案每月有免費訊息額度，原則上以 LINE 官方公告為準）。
2. 帳號「設定 › Messaging API」按「啟用」，選一個 Provider。
3. 到 [LINE Developers Console](https://developers.line.biz/console/) 找到這個 Channel：
   - **Basic settings** 複製 `Channel secret` → `line_secret_<品牌>`
   - **Messaging API** 分頁最下面按 **Issue** 取得長期 `Channel access token` → `line_token_<品牌>`
4. Webhook URL 填：`https://你的網域/line/webhook/<品牌>`，打開 **Use webhook**；關掉「自動回應訊息」。
   - 系統只綁 `127.0.0.1`，對外要經過 HTTPS 反向代理或 Cloudflare Tunnel 之類的工具，並把網域加進 `OPS_PUBLIC_HOSTS`。
5. 建議先用一個**測試用官方帳號**，確認訊息正常再換正式帳號。

## 2. LINE Pay

1. 到 [LINE Pay 商家中心](https://pay.line.me/) 申請（需要公司或商號資料，審核時間依官方為準）。
2. 先到 [LINE Pay Sandbox](https://pay.line.me/tw/developers/techsupport/sandbox/creation) 申請**沙盒**帳號測試。
3. 取得 `Channel ID`、`Channel Secret Key` → `linepay_channel_id`、`linepay_channel_secret`。
4. 系統預設是沙盒模式；確認流程沒問題後，在「設定 › LINE Pay」改成正式（settings `linepay_mode=production`）。
5. 正式環境的伺服器對外 IP 要登記在 LINE Pay 商家後台的白名單。
6. 原則上建議：真人用自己的帳號付一筆小額、確認入帳與退款都正常後才開放給客人。

## 3. Google 日曆（選用）

1. 到 [Google Cloud Console](https://console.cloud.google.com/) 建立專案，啟用 **Google Calendar API**。
2. 「OAuth 同意畫面」選外部、加入自己為測試使用者；權限只需要 `calendar.app.created`（只碰本程式建立的日曆）。
3. 「憑證 › 建立 OAuth 用戶端 ID」選**網頁應用程式**，授權重新導向 URI 填 `http://127.0.0.1:4781/oauth/callback`（或你的對外網址）。
4. 把用戶端 ID／密碼填進「設定 › Google 日曆」（或環境變數），再按「連結 Google」完成授權（系統會自己存 `google_refresh_token`）。

## 4. Anthropic API（AI 記帳、對話重點，選用）

1. 到 [Anthropic Console](https://console.anthropic.com/) 註冊、儲值，在 **API Keys** 建立金鑰。
2. 設定 `OPS_SECRET_ANTHROPIC_API_KEY`，並 `pip install -r requirements-optional.txt`。
3. 建議在 Console 設定每月用量上限。客戶訊息送 AI 前系統會先遮罩姓名、電話、地址，但原則上仍請自行評估個資規範。

## 5. 手機推播（Web Push，選用）

VAPID 金鑰由系統第一次啟動時自動產生，存在 `OPS_DATA` 資料夾，不用申請。需要 HTTPS 網址才能在手機上訂閱。
